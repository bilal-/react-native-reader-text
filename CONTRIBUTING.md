# Contributing

Contributions are welcome, especially around native selection behavior, RTL/LTR text, multilingual typography, accessibility, Expo compatibility, and documentation.

Before opening a pull request:

1. Keep the library generic. App-specific workflows such as note storage, share UI, and custom popovers should stay in consumer apps.
2. Add or update tests for TypeScript utilities and API behavior.
3. Document platform differences instead of promising pixel-perfect parity.
4. Run `npm test` and `npm run typecheck`.
